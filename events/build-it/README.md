# Build IT

**Build IT** was an online event organized by the MicroClub IT Section, built around one idea: *research first, build second*.

Teams of 4–5 members were each assigned a technical theme, such as a protocol, an algorithm or a framework. They had to:

1. **Research** the theme until they understood how it works.
2. **Document** it in a `README.md` written like a technical article: the concept explained in depth, how it was applied in the project, architecture diagrams and setup instructions.
3. **Build** a working website or app that shows the technology in action.

Each team also recorded a short video explaining the concept and demoing the result. Submissions were judged on documentation, implementation, presentation and creativity.

## What's in this folder

Each subfolder is one team's submission: the source code and the README that documents their theme.
