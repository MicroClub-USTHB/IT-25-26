# 🕌 Smart Prayer Times App – React Challenge

## 📌 Project Overview

The Prayer Times App (مواقيت الصلاة) is a modern React application that helps users view accurate daily prayer times based on their selected location.
This project is designed as a hands-on challenge to simulate real-world frontend development, focusing on state management, React hooks, and UI design using Tailwind CSS.

Users will be able to:

- View daily prayer times for a selected city
- See a live countdown to the next prayer
- Change location dynamically

---

## 🎯 Learning Objectives

By completing this challenge, you should be able to:

- React Hooks Mastery
- State Management
- Data Fetching & Async Logic
- UI Development with Tailwind CSS
- Component Architecture

## 🏗 Project Requirements

### 🎯 Core Features

You must:

- Display prayer times based on city
  Show:
